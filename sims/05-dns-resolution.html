    Notes

    • The name example.com is reserved for documentation (RFC 2606); addresses 192.0.2.x are the TEST-NET-1 documentation range (RFC 5737).
    • A cached record may be used until its TTL expires (RFC 1035 §3.2.1, RFC 1034 §4.3.5). Negative answers are cached too, for the lesser of the SOA TTL and SOA MINIMUM (RFC 2308 §5).

    Simplifications

    • One recursive resolver with one cache; real deployments have many resolvers and caches (OS, browser, ISP, forwarders) that each hold their own copies.
    • Referrals show a single name server per level; glue records, DNSSEC, EDNS, TCP fallback, query name minimisation and retries are omitted.
    • Delegation (NS) TTLs are fixed at an example 172800 s; resolvers may ignore or cap TTLs with their own minimum and maximum, so real stale windows can differ.
    • The “lower the TTL” worst case assumes the change time is known, caches obey TTLs, and no resolver serves stale data beyond expiry.
    • Negative TTL uses min(SOA TTL, SOA MINIMUM) per RFC 2308 §5; the NXDOMAIN response is assumed to include the SOA record. Addresses are documentation examples.

    All numbers on this page are examples chosen for teaching, not measurements.
