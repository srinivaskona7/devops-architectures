Simplifications

  • IPv4 only; IPv6 is not covered. Addresses are treated as unsigned 32-bit integers.
  • /31 is shown as 2 usable (RFC 3021 point-to-point) and /32 as 1; many devices and cloud services do not treat these as ordinary subnets.
  • AWS mode implements the documented 5 reserved addresses per subnet and the /16 to /28 size range for VPC and subnet CIDRs; limits can change, so check the current AWS docs. Secondary CIDR rules, BYOIP and IPAM behaviour are not modelled.
  • The overlap check compares address ranges only; it does not model route tables, NAT or which attachments exist. Subnet lists are capped at 4096 rows.
  • Example addresses use private RFC 1918 ranges.

All numbers on this page are examples chosen for teaching, not measurements.
